# Skandi Studio — студия скандинавского дизайна и мебели

Сайт-лендинг на Astro. **Дизайн-система целиком перенесена с сайта
dr.chashchina** (референс — farmminerals.com/products/croptab: швейцарская
типографика, full-bleed, тонкие линии, оливковая палитра; галерея — по
мотивам prmpt). Отличия от донора: розовый трек убран (только зелёный
авокадо + нейтрали), hero — с видео вместо портрета, текст прижат к низу.
Подробности: [DESIGN.md](DESIGN.md) (описывает донора; розовое — игнорировать)
и [SPACING.md](SPACING.md) (пульт отступов).

## Команды

- `npm run dev` — дев-сервер на `127.0.0.1:4331` (хост обязателен, порт свой).
- `npm run build` / `npm run preview` (порт 4332).

## Статус контента

**Все тексты — рыба** под тему «скандинавская мебель», написана как
образец композиции: цифры, издания, история студии выдуманы. Фото —
сгенерированные градиентные заглушки в `public/photos/web/` (01–10 +
strip1/strip2), видео `ripple.mp4`/`serum.mp4` — абстрактные футажи-времянки.
Заменять на реальные материалы заказчика, сохраняя размеры: галерея 2:3
(~800×1200 webp, quality 80), стрипы широкие (~2000×900).

## Структура

- [src/pages/index.astro](src/pages/index.astro) — вся главная: данные секций в frontmatter, разметка, стили.
- [src/layouts/Layout.astro](src/layouts/Layout.astro) — шрифт Onest, global.css, скрипты: посимвольный ревил `[data-split]`, IntersectionObserver для `.reveal`/`.reveal-group`, русский типограф ([src/lib/typo.ts](src/lib/typo.ts)).
- [src/components/Gallery.astro](src/components/Gallery.astro) — галерея prmpt-типа: 12-колоночная рассыпанная сетка, RAF-скейл карточек.
- [src/components/Header.astro](src/components/Header.astro), [Footer.astro](src/components/Footer.astro), страницы [thanks](src/pages/thanks.astro) и [404](src/pages/404.astro).
- [src/styles/global.css](src/styles/global.css) — все токены и предохранители. Числа в компонентах не повторять — крутить токены.
- Пути к ассетам — только через `asset()` из [src/lib/asset.ts](src/lib/asset.ts).

## Принципы дизайна (кратко)

- Один цветовой трек: зелёный авокадо (#5c6b3c/#404f1d) + шалфей (#aab98f) + нейтрали. Слот под второй акцент размечен в global.css (`.section--alt`), но пуст. `<mark>` всегда шалфейный.
- Onest, тонкие крупные заголовки (300–330), отрицательный трекинг; **капс запрещён**, жирный/курсив в наборе запрещены (в CSS предохранители).
- Скругления 0. Линии 1px и только структурные (спек-листы, шапка/футер, ось таймлайна).
- Мера строки токенами `--measure-*` в `ch` на самом текстовом элементе.
- Ритм: `--section-gap` и модификаторы `.section--tight/--flush-*`.
- Анимации без библиотек: `[data-split]` (посимвольно, случайный порядок), `.reveal`/`.reveal-group` (fade/rise каскадом), галерея на RAF с lerp. Всё гаснет при `prefers-reduced-motion`.
- Hover — только opacity (.7). Яркие цвета запрещены, красный — только ошибки.
- Не ставить `text-align: center`, буллиты, hairline-линии в перечислениях.
